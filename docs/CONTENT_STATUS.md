## 本文の扱い

確認できた運営資料には、短いメモや用語のみの記載が含まれていました。定義、適用範囲、例外、処分、施行日、承認情報を確認できなかったため、住民向けの公式ルールとして掲載していません。開発やサーバー運用の内部方針も、住民向けのルールには使用していません。

参考にした他サーバーのサイトは情報整理と使いやすさの検討に使い、本文・画像・CSSを転載していません。

## 正式公開に必要な確認

1. 運営が正式なルール本文・要約・カテゴリーを確定する。
2. 用語の定義、例外、適用範囲、必要な処分内容を確認する。
3. 運営が承認したカードだけ、`status` を `published` に変更する。
4. 重複しないルール番号・固定ID・更新日を指定する。
5. サイトのバージョンと更新日を更新し、住民向けの変更履歴を追加する。
6. 公式の外部リンクを確認して設定する。
7. `npm run validate` と公開画面の確認を終えてCommitする。

本文や公式リンクが未確定の部分は「準備中」「運営確認中」を維持します。一般的なFiveMルールを自動的にNicoGuraの公式ルールへ追加しないでください。

## 引き継ぎ時に公開しない情報

この公開リポジトリには、運営資料の原本、内部のファイルパス、サーバーIP、設定ファイル、認証情報、管理者の個人情報を追加しません。必要な内部確認記録は運営内で管理し、サイトには承認済みの住民向け本文だけを移してください。
